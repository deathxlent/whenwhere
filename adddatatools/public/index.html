添加地图说明

方式一：在线瓦片地图

选择 OSM 或在线瓦片URL类型，直接使用网络地图。


方式二：本地瓦片地图

1. 将瓦片图片放入 adddatatools/tiles/地图编码/ 目录

2. 瓦片命名格式：{z}/{x}/{y}.png

3. 选择 "自定义瓦片" 类型，瓦片URL填 /tiles/地图编码/{z}/{x}/{y}.png

4. 根据瓦片坐标系选择 CRS 类型（游戏地图通常用 simple）


方式三：导入现有地图

如果有类似 test/zeldamap 格式的地图，直接复制 tiles 目录到 tiles 文件夹下，然后添加对应地图配置即可。

导出数据

导出的数据可以直接导入到 ww 和 hsd 应用中。推荐使用 JSON 格式，兼容性更好。

JSON 格式导入说明：
  • 所有数据都用 code 编码关联，导入时自动匹配
  • 地图和分类如果编码已存在则跳过（不会覆盖）
  • 子分类和事件会根据分类 code 和子分类 code 自动关联

导入数据

可以导入 JSON 格式的数据文件，用于合并数据或备份恢复。
