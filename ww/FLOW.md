```
│  │  用户名: [ player1                          ]       │   │
│  │  Token:   [ (新用户留空，自动生成)            ]       │   │

                Token 为空？─────────┬─────────┐
                (检查输入框)         │         │
                                   │ 有     无
                                   │         │
                                   ▼         ▼
                        登录流程      注册流程
                                   │         │
    ┌──────────────────────────────┘         └──────────┐
    │                                                    │
    ▼                                                    ▼
POST /api/auth/login                          POST /api/auth/register
    │                                                    │
    ▼                                                    ▼
  解密 Token                                     生成随机 Token
  验证 Token hash                                用户名唯一性检查
    │                                                    │
    └──────────────────┬─────────────────────────────────┘
                       │
                       ▼
                返回用户信息
                { user_id, username, token }
                       │

          保存 Token 到 localStorage
          保存用户信息到 appState
                       │
                       ▼
                跳转到主页面
```

### 1.2 Token 认证机制

```
Token 生成与存储：
  1. 服务端生成随机字符串
  2. 使用 AES-256-CBC 加密生成 Token
  3. 计算 SHA-256 哈希存入数据库
  4. 返回加密 Token 给客户端

Token 验证：
  1. 客户端发送加密 Token
  2. 服务端解密 Token
  3. 计算 SHA-256 哈希
  4. 与数据库中的哈希对比
  5. 返回验证结果
```

## 6. 统计与排行榜流程

### 6.1 个人统计流程

```
      主页面点击「我的统计」 或
      个人统计页面切换时间段
                 │
                 ▼
  GET /api/game/stats/:userId
  ?period=all|week|month|year
                 │
                 ▼
      根据 period 计算日期范围
      (week: 本周, month: 本月, ...)
                 │
                 ▼
      查询 game_stats 表
      WHERE user_id = ? AND stat_date BETWEEN ? AND ?
                 │
                 ▼
      计算汇总统计：
      - total_games: 总局数
      - total_distance: 总距离误差
      - avg_distance: 平均距离误差
```

### 6.2 排行榜流程

```
        主页面切换排行榜 Tab 或 时间段
                    │
                    ▼
       GET /api/game/leaderboard
       ?period=all|week|month|year
                    │
                    ▼
        根据 period 计算日期范围
                    │
                    ▼
     聚合查询所有用户的统计数据
     (JOIN game_stats + users)
                    │
                    ▼
         计算每个用户的平均指标
                    │
                    ▼
        按 6 个维度分别排序取 Top 10：
        ┌──────────────────────────────────┐
        │ by_games:        总局数 降序    │
        │ by_avg_distance: 均距 升序      │
        │ by_avg_time:     均时差 升序     │
        │ by_avg_elapsed:  均耗时 升序     │
        │ by_precise_loc:  精准位置率 降序 │
        │ by_precise_time: 精准时间率 降序 │
        └──────────────────────────────────┘
                    │
                    ▼
        返回 6 个排行榜数据给前端
                    │
                    ▼
           前端渲染排行榜列表
           前三名高亮显示
```

## 7. 投票反馈流程

```
      结果页面点击「👍 好题」或「👎 烂题」
                      │
                      ▼
         POST /api/game/vote
         { user_id, event_id, vote_type }
                      │
                      ▼
         检查是否已投过票（votes 表）
                      │
         已投票？ ──┬───┐
                    │是  │ 否
                    ▼     ▼
              UPDATE    INSERT
              (更改类型)  (新增记录)
                    │     │
                    └─┬───┘
                      │
                      ▼
          GET /api/game/vote/:eventId
          ?user_id=xxx
                      │
                      ▼
           查询当前投票统计：
           - up_count: 点赞数
           - down_count: 点踩数

           返回统计信息给前端

                      ▼
```
