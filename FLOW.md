## 2. 数据生命周期

一道题目（事件）从创建到被玩家游玩的完整生命周期：

```
  创建草稿      提交审核      审核通过      玩家游玩      统计分析
     │            │            │            │            │
     ▼            ▼            ▼            ▼            ▼
  ┌─────┐    ┌───────┐    ┌────────┐    ┌──────┐    ┌────────┐
  │草稿 │───→│待审核 │───→│已发布 │───→│已游玩│───→│已归档 │
  └─────┘    └───────┘    └────────┘    └──────┘    └────────┘
     │            │            │            │            │
     │ 编辑       │ 投票       │ 编辑        │ 收藏       │
     │ 删除       │ 拒绝       │ 删除        │ 分析       │
     ▼            ▼            ▼            ▼            ▼
  ┌─────┐    ┌───────┐    ┌────────┐    ┌──────┐    ┌────────┐
  │已修改│    │已拒绝 │    │已删除 │    │已收藏│    │  备份   │
  └─────┘    └───────┘    └────────┘    └──────┘    └────────┘
```

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| **草稿** | 初始状态，未提交审核 | 编辑、删除、提交审核 |
| **待审核** | 已提交，等待审核通过 | 投票（通过/拒绝）、编辑 |
| **已拒绝** | 审核未通过 | 编辑后重新提交、删除 |
| **已发布** | 审核通过，玩家可见 | 编辑、删除、导出 |
| **已游玩** | 被玩家玩过，有答题记录 | 收藏、分析、投票反馈 |
| **已收藏** | 被玩家加入收藏 | 查看答案分析、取消收藏 |
| **已归档** | 长期未使用 | 备份、删除 |

## 3. HSD → WW 数据同步流程

### 3.1 方式一：数据库共享（推荐）

HSD 和 WW 共用同一个 SQLite 数据库，实现实时数据同步。

```
┌─────────────────┐      ┌─────────────────┐
│   HSD 维护系统   │      │   WW 游戏系统    │
└────────┬────────┘      └────────┬────────┘
         │                        │
         └──────────┬─────────────┘
                    │
                    ▼
           ┌─────────────────┐
           │  共享数据库      │
           │  whenwhere.db   │
           └─────────────────┘
                    │
                    ▼
      HSD 写入 ═══════════►  WW 读取
      (创建/更新/删除)      (查询/展示)
```

**配置方法**：
修改 `ww/server/db.js` 指向 HSD 的数据库文件：
```javascript
const DB_PATH = path.join(__dirname, '..', '..', 'hsd', 'db', 'hsd.db');
```

**注意事项**：
- 两个系统需要有一致的数据库 schema
- HSD 负责写操作，WW 主要是读操作
- 需注意并发写入问题（SQLite 支持并发读，单线程写）

### 3.2 方式二：导出/导入（手动同步）

适合 HSD 和 WW 部署在不同服务器的场景。

```
┌─────────────────┐                          ┌─────────────────┐
│   HSD 服务器     │                          │   WW 服务器      │
│                  │                          │                  │
│  1. 选择事件     │   ┌───────────────┐    │  5. 解压 ZIP     │
│  2. 导出为 ZIP   │──→│  data.zip     │───→│  6. 复制图片     │
│  3. 包含:        │   │  • events.json│    │  7. 导入数据     │
│     • 事件数据   │   │  • images/    │    │  8. 验证数据     │
│     • 图片文件   │   │  • geojson/   │    │                  │
│     • 附件       │   └───────────────┘    │                  │
└─────────────────┘                          └─────────────────┘
```

**导出流程（HSD）**：
1. 进入事件管理页面
2. 筛选需要导出的事件
3. 点击「批量操作」→「导出」
4. 选择「导出为 ZIP（含图片）」
5. 下载生成的 ZIP 文件

**导入流程（WW）**：
1. 将 ZIP 文件上传到 WW 服务器
2. 解压到临时目录
3. 复制 `images/` 到 `ww/static/images/`
4. 复制 `geojson/` 到 `ww/static/geojson/`
5. 读取 `events.json` 并导入到 WW 数据库
6. 验证数据完整性

### 3.3 方式三：API 同步（自动化）

通过 HTTP API 实现定时自动同步。

```
┌─────────────────┐                          ┌─────────────────┐
│   HSD 服务器     │                          │   WW 服务器      │
│                  │   定时拉取              │                  │
│  GET /api/export │◄─────────────────────────┤  Cron 任务       │
│                  │   (增量: 上次同步时间)   │                  │
│  返回 JSON 数据  ├─────────────────────────►│  导入数据        │
└─────────────────┘                          └─────────────────┘
```

**同步策略**：
- **全量同步**：首次部署时同步所有数据
- **增量同步**：仅同步上次同步后的变更
- **冲突解决**：以 HSD 数据为准，覆盖 WW 数据

## 4. 完整用户旅程

### 4.1 管理员旅程

```
1. 访问 HSD (http://localhost:3001)
   │
   ▼
2. 登录管理员账号
   │
   ▼
3. 创建分类结构
   ├─ 中国历史
   │  ├─ 古代史
   │  ├─ 近代史
   │  └─ 现代史
   └─ 世界地理
      └─ 世界地标
   │
   ▼
4. 配置地图（如使用默认 OSM/高德可跳过）
   │
   ▼
5. 添加事件（题目）
   ├─ 填写标题、描述、时间
   ├─ 上传图片（至少1张，最多4张）
   ├─ 地图上选择位置或绘制区域
   ├─ 选择分类和子分类
   └─ 设置渐进式显示时间
   │
   ▼
6. 提交审核（或直接发布）
   │
   ▼
7. [可选] 使用 AI 提取功能辅助填写
   │
   ▼
8. 审核通过，事件变为「已发布」
   │
   ▼
9. 数据同步到 WW，玩家可见
   │
   ▼
10. 查看统计和反馈，优化题目质量
```

### 4.2 贡献者旅程

```
1. 注册/登录 HSD
   │
   ▼
2. 添加事件（创建草稿）
   │
   ▼
3. 提交审核
   │
   ▼
4. 等待其他贡献者审核
   │
   ▼
5. 审核通过 → 已发布
   审核拒绝 → 编辑后重新提交
   │
   ▼
6. 查看自己贡献的题目的游玩统计
```

### 4.3 玩家旅程

```
1. 访问 WW (http://localhost:3000)
   │
   ▼
2. 输入用户名（新用户自动注册）
   │
   ▼
3. 选择感兴趣的分类
   ├─ 勾选分类
   └─ 勾选子分类（至少一个）
   │
   ▼
4. 点击「开始游戏」
   │
   ▼
5. 游戏进行中
   ├─ 30秒倒计时开始
   ├─ 20秒时显示第2张图
   ├─ 10秒时显示第3张图
   ├─ 点击地图选择位置
   └─ 输入年份
   │
   ▼
6. 提交答案（手动或自动）
   │
   ▼
7. 查看结果
   ├─ 得分详情
   ├─ 距离/时间误差
   ├─ 精准奖励
   ├─ 耗时加成
   ├─ [可能] 新成就解锁
   └─ [可能] 段位提升
   │
   ▼
8. 后续操作
   ├─ 再来一局
   ├─ 收藏题目
   ├─ 查看别人怎么答
   └─ 投票（好题/烂题）
   │
   ▼
9. [可选] 查看统计和排行榜
   │
   ▼
10. [可选] 进入成就系统查看进度
```

**共用表**（HSD 和 WW 都使用）：
- `categories` - 分类
- `sub_categories` - 子分类
- `maps` - 地图配置
- `events` - 事件（题目）
- `event_images` - 事件图片

**WW 独有表**（游戏数据）：
- `users` - 用户
- `game_sessions` - 游戏会话
- `game_answers` - 答题记录
- `game_stats` - 每日统计
- `favorites` - 收藏
- `votes` - 投票
- `achievements` - 成就定义
- `user_achievements` - 用户成就
- `rank_history` - 段位历史
