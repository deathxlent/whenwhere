```
选择分类 → 查看子分类列表 → [新增/编辑/删除] → 表单填写 → 验证 → 保存 → 刷新列表
```

### 2.1 导出清单格式 (manifest)

ZIP 包中的 `manifest.json` 包含：
```json
{
  "version": "1.0",
  "exported_at": "2026-06-22T10:00:00.000Z",
  "exported_by": "hsd",
  "filter": {
    "category_ids": [1, 3],
    "sub_category_ids": [1, 2, 5]
  },
  "include_images": true,
  "include_tiles": false,
  "statistics": {
    "categories": 2,
    "sub_categories": 3,
    "maps": 2,
    "events": 156,
    "images": 312
  },
  "checksums": {
    "data.json": "sha256:..."
  }
}
```
