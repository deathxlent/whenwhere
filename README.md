# 🎮 WhenWhere 何时何地 —— 在游戏中认识世界

> **一张图片，一个故事。你能猜出它发生在哪里？又发生在何时？**
>
> WhenWhere 是一款结合**地理**与**历史**的双维度猜测游戏，让你在娱乐中不知不觉增长知识。

---

## 🚀 一键开始游玩

**Windows 用户：双击运行「一键开玩.bat」** → 自动检查环境 → 启动游戏 → 浏览器自动打开

就这么简单！无需复杂的安装配置。

## 🎯 为什么玩 WhenWhere？

### 📚 寓教于乐，不知不觉涨知识
- **地理素养**：在地图上定位著名事件，培养空间感知能力
- **历史眼光**：记住重要事件的时间脉络，建立时间轴思维
- **跨界联系**：理解同一时期、不同地区发生的历史事件关联
- **记忆深刻**：通过主动猜测和即时反馈，记忆效果远超被动阅读

### 🏆 丰富的游戏机制，越玩越上瘾
| 特色 | 描述 |
|------|------|
| **🌍 双维度猜测** | 同时猜**地点**+**时间**，比传统 GeoGuessr 更有挑战 |
| **⏱️ 渐进式提示** | 30秒内逐步展示更多图片，紧张刺激 |
| **🎯 精准判定** | 距离≤50km、时间≤1年即可获得「精准」称号 |
| **🏅 成就系统** | 9种成就、3个等级，挑战你的极限 |
| **📈 段位进阶** | 青铜→王者，8个段位等你攀登 |
| **📊 答案分析** | 查看所有玩家的答题分布，发现有趣的认知偏差 |
| **🌏 多主题题库** | 中国历史、世界地理、游戏世界……总有你喜欢的 |

### 🧠 锻炼的能力
- **观察力**：从图片细节中寻找线索
- **推理力**：根据线索逻辑推断位置和时间
- **记忆力**：记住重要事件的时空坐标
- **决策力**：在有限时间内做出最佳判断

## 🎮 怎么玩？30秒上手

### 游戏流程
```
1️⃣ 选择题库 → 2️⃣ 观看图片线索 → 3️⃣ 地图上点选地点
   ↓
4️⃣ 输入年份 → 5️⃣ 提交答案 → 6️⃣ 查看结果
   ↓
7️⃣ 学习真实事件 → 8️⃣ 下一题！
```

### 得分规则（满分100+）
- **📍 地点分 (0-50)**：距离越近分越高
- **📅 时间分 (0-50)**：年份越准分越高
- **✨ 精准奖励 (+10)**：距离≤50km 且 时间≤1年
- **⚡ 速度加成 (1.0~1.5x)**：答得越快，倍数越高

## 🚀 快速开始

### 🪟 Windows 用户（推荐）

**只需一步：双击「一键开玩.bat」**

脚本会自动：
- ✅ 检查 Node.js 环境

```bash
# 2. 进入游戏目录

npm install

# 4. 初始化数据库
npm run init-db

# 5. 启动游戏
npm start

# 6. 浏览器访问
# http://localhost:3000
```

## ❓ 常见问题

**Q: 需要联网吗？**
A: 游戏本身可以离线运行，但地图瓦片默认使用在线服务。如需完全离线，可将瓦片下载到 `ww/static/tiles/` 目录。

**Q: 可以自己添加题目吗？**
A: 当然！启动 HSD 维护系统（端口 3001）即可管理题库。

**Q: 数据会丢失吗？**
A: 所有数据保存在本地 SQLite 数据库文件中，只要不删除 `ww/db/whenwhere.db` 就不会丢失。
